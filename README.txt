PRODUCT MANAGER - PHP + MySQL

1. Pastikan XAMPP Apache dan MySQL aktif.
2. Letakkan folder product-manager di C:\xampp\htdocs\
3. Buka phpMyAdmin atau MariaDB.
4. Jalankan isi database/store_db.sql.
5. Buka:
   http://localhost/product-manager/public/

Catatan:
- Project ini dibuat mengikuti konsep demo project pada PPT:
  CRUD, validasi server-side, PDO/prepared statement,
  PRG, escaping output, Box Model, Flexbox, dan CSRF.
